Cubase 16 自動ホイールナッジ 設定ガイド（単体版）

Cubase 16 がアクティブなときだけ有効になり、MIDIノートをクリックした直後だけの自動ホイールナッジ（1msなど任意の単位で調整可能）と、他所クリック時の通常スクロール即復帰を実現します。

1. 操作割り当て一覧

操作方法Cubase上の動作内部処理（送信キー）
MIDIノート選択直後に ホイール上右へナッジ（設定グリッド単位で後ろへ移動）]（高速メモリ判定ON時）
MIDIノート選択直後に ホイール下左へナッジ（設定グリッド単位で前へ移動）[（高速メモリ判定ON時）
他所をクリック / Esc遅延ゼロ（約0.002秒）で通常のスクロールへ即復帰クリックごとに再判定してOFF

2. Cubase 16 本体側の事前設定

  • ナッジ単位（グリッド）の調整：
    エディタ上部のスナップ／グリッド設定で、1 ms や 1/16 など動かしたい任意の単位に調整可能です（スナップOFF時はズーム倍率に応じた微調整になります）。
  • キーボードショートカット設定（編集 ＞ キーボードショートカット ＞ ナッジ）：
    • ナッジ ＞ 左へ移動：単一キーの [ を割り当て
    • ナッジ ＞ 右へ移動：単一キーの ] を割り当て

3. 自動ナッジの判定原理と初期設定（環境別の幅取得手順）

MIDIノートを選択すると、キーエディタ左側のピアノ鍵盤エリアのうち、選択したノートの高さ（Y座標）に対応する鍵盤がハイライト（ピンク等の色付き、またはグレーノート色）に変化します。

  • 色付きノート＆グレーノート自動判定：特定の色コード固定ではなく、彩度（色味）がある色および鍵盤背景（白鍵の明るいグレー・黒鍵の暗いグレー）を除外したノート特有のグレー色を自動判別するため、トラックカラーや選択状態による明度変化に左右されません。
  • メモリ一括転送（BitBlt）による約0.002秒の無遅延判定：クリックしたY座標（my）の前後（上下 ±150px＝2〜3鍵盤分以上の余裕）をWindows APIでメモリ上に一括コピーして1px単位で高速スキャンします。ノートの際をクリックした際の取りこぼしを防ぎつつ、選択解除（空白クリック）時も遅延ゼロで即座に通常スクロールへ戻ります。
  • タイムライン移動時の自動復帰：ノートを選択したままでも、マウスカーソルがクリック位置から上下 150px 以上離れる（上のタイムラインへ移動する）と自動的に通常のホイールスクロールへ切り替わります。

【初回セットアップ】ご自身の環境での「鍵盤判定エリア（X座標）」取得と貼り付け方法

  1. まず下のスクリプト（nudge.ahk）をダウンロードしてダブルクリックし、常駐させます。
  2. Cubaseのキーエディタで適当なMIDIノート（黒鍵・白鍵）をクリックして選択状態にします（左側のピアノ鍵盤の該当音程が光ります）。
  3. 左端（KeyAreaMinX）の取得：鍵盤が光っている部分の左側（薄いハイライトも含めて 【ノート判定】 になる範囲）にマウスを乗せて、\ キー（ひらがなの「ろ」のキー、または BackSpace左隣の「ー」のキー）を押します。画面に表示された X座標 をメモします。
  4. 右端（KeyAreaMaxX）の取得：黒鍵のノートを選択した際、鍵盤の右側は白くハイライトされるため、右端は「黒鍵の左右中央部（確実に色・ノート判定が残る位置）」にマウスを乗せて、同じく \ キー（ひらがなの「ろ」／「ー」のキー）を押します。表示された X座標 をメモします。
  5. nudge.ahk をメモ帳などで開き、スクリプト上部にある 【環境設定エリア】 のうち、KeyAreaMinX と KeyAreaMaxX の数字だけを書き換えて上書き保存し、タスクトレイの緑の「H」アイコンを右クリック ＞「Reload Script」を実行します。
; ▼▼ スクリプト上部のこの部分にある 2つの数字（42 と 58）だけを書き換えてください ▼▼
global KeyAreaMinX := 42        ; 鍵盤判定エリアの左端 X座標（初期値: 42）
global KeyAreaMaxX := 58        ; 鍵盤判定エリアの右端 X座標（初期値: 58 ※黒鍵中央部）

4. AutoHotkey v2 スクリプト（ナッジ単体版・BitBlt無遅延スキャン）

下のボタンから .ahk ファイルをダウンロードし、ダブルクリックして常駐させてください。

#Requires AutoHotkey v2.0

if not A_IsAdmin {
    Run '*RunAs "' A_ScriptFullPath '"'
    ExitApp
}

SetTitleMatchMode "RegEx"
#HotIf WinActive("ahk_exe i).*Cubase.*\.exe")

SetKeyDelay 10, 10

; ==============================================================================
; 【環境設定エリア】ご自身のモニター解像度に合わせて数字を合わせてください
; ==============================================================================
global KeyAreaMinX := 42        ; 鍵盤判定エリアの左端 X座標（初期値: 42）
global KeyAreaMaxX := 58        ; 鍵盤判定エリアの右端 X座標（初期値: 58）
; ==============================================================================

global IsNoteSelectedFlag := false
global SelectedNoteY := 0

; 【座標・色取得ヘルパー】鍵盤の光る部分の上で \ キー（ひらがなの「ろ」／「ー」キー）を押す
vkDC::
vkE2:: {
    CoordMode "Mouse", "Screen"
    CoordMode "Pixel", "Screen"
    MouseGetPos(&mx, &my)
    col := PixelGetColor(mx, my)
    isNote := IsNoteColor(col) ? "【ノート判定（色付き or グレーノート）】" : "【鍵盤背景（除外）】"
    A_Clipboard := "X座標: " mx " / 色コード: " col
    ToolTip "コピー完了！`nX座標: " mx "`n色コード: " col "`n判定: " isNote
    SetTimer () => ToolTip(), -5000
}

; ==============================================================================
; 自動ナッジ（メモリ一括コピーによる 0.002秒 超高速判定）
; ==============================================================================
~LButton Up:: {
    global IsNoteSelectedFlag, SelectedNoteY
    global KeyAreaMinX, KeyAreaMaxX

    Sleep 35 ; CubaseのUI描画完了待ち
    CoordMode "Mouse", "Screen"
    MouseGetPos(&mx, &my)
    
    SearchTop := Max(0, my - 150)
    SearchHeight := 300
    SearchWidth := Max(1, KeyAreaMaxX - KeyAreaMinX + 1)
    
    ; 1. 鍵盤側（KeyAreaMinX〜KeyAreaMaxX, my±150px）を一括メモリ取得して1px単位で超高速判定
    FoundNoteColor := FastScanAreaForNote(KeyAreaMinX, SearchTop, SearchWidth, SearchHeight)
    
    ; 2. 鍵盤側で弾かれた場合でも、クリックした位置(mx, my)自体にノートがあれば救済
    if (!FoundNoteColor && mx > KeyAreaMaxX + 20) {
        FoundNoteColor := FastScanAreaForNote(mx, Max(0, my - 2), 1, 5)
    }
    
    if (FoundNoteColor) {
        IsNoteSelectedFlag := true
        SelectedNoteY := my
    } else {
        IsNoteSelectedFlag := false
        SelectedNoteY := 0
    }
}

~Esc:: {
    global IsNoteSelectedFlag
    IsNoteSelectedFlag := false
}

#HotIf WinActive("ahk_exe i).*Cubase.*\.exe") && IsNoteSelectedFlag && IsMouseNearClickY()
WheelUp::SendEvent "{vkDD}"   ; 右へナッジ（]）
WheelDown::SendEvent "{vkDB}" ; 左へナッジ（[）
#HotIf

IsMouseNearClickY() {
    global SelectedNoteY
    CoordMode "Mouse", "Screen"
    MouseGetPos(, &my)
    Margin := 150
    return (Abs(my - SelectedNoteY) <= Margin)
}

; ==============================================================================
; 超高速エリアスキャン関数（BitBltで画面を一括メモリ転送し、5秒→0.002秒に短縮）
; ==============================================================================
FastScanAreaForNote(x, y, w, h) {
    hdcScreen := DllCall("GetDC", "Ptr", 0, "Ptr")
    hdcMem := DllCall("CreateCompatibleDC", "Ptr", hdcScreen, "Ptr")
    
    bi := Buffer(40, 0)
    NumPut("UInt", 40, bi, 0)
    NumPut("Int", w, bi, 4)
    NumPut("Int", -h, bi, 8) ; トップダウンDIB
    NumPut("UShort", 1, bi, 12)
    NumPut("UShort", 32, bi, 14) ; 32bit BGRA
    
    pBits := 0
    hbm := DllCall("CreateDIBSection", "Ptr", hdcMem, "Ptr", bi, "UInt", 0, "Ptr*", &pBits, "Ptr", 0, "UInt", 0, "Ptr")
    obm := DllCall("SelectObject", "Ptr", hdcMem, "Ptr", hbm, "Ptr")
    
    ; 画面の指定領域をメモリへ一瞬で一括コピー（0x00CC0020 = SRCCOPY）
    DllCall("BitBlt", "Ptr", hdcMem, "Int", 0, "Int", 0, "Int", w, "Int", h, "Ptr", hdcScreen, "Int", x, "Int", y, "UInt", 0x00CC0020)
    
    found := false
    totalPixels := w * h
    offset := 0
    Loop totalPixels {
        colorInt := NumGet(pBits, offset, "UInt") & 0xFFFFFF
        if (IsNoteColor(colorInt)) {
            found := true
            break
        }
        offset += 4
    }
    
    DllCall("SelectObject", "Ptr", hdcMem, "Ptr", obm)
    DllCall("DeleteObject", "Ptr", hbm)
    DllCall("DeleteDC", "Ptr", hdcMem)
    DllCall("ReleaseDC", "Ptr", 0, "Ptr", hdcScreen)
    
    return found
}

; ==============================================================================
; 判定用関数：色付きノート ＋ グレーノート対応（鍵盤の白黒グレーだけを除外）
; ==============================================================================
IsNoteColor(colorInt) {
    r := (colorInt >> 16) & 0xFF
    g := (colorInt >> 8) & 0xFF
    b := colorInt & 0xFF
    
    maxC := Max(r, g, b)
    minC := Min(r, g, b)
    if ((maxC - minC) > 15) {
        return true
    }
    
    avg := (r + g + b) / 3
    if ((avg >= 40 && avg <= 68) || (avg >= 95 && avg <= 130)) {
        return true
    }
    
    return false
}

5. Windows起動時の自動常駐（スタートアップ登録）と運用

  • スタートアップ登録手順：保存した .ahk ファイルを右クリック ＞「ショートカットの作成」を実行。Win + R を押して shell:startup と入力して開き、作成したショートカットをそのフォルダへ移動します。
  • 状態ズレのリセット：何らかの拍子に動作がおかしくなった場合は、タスクトレイの緑の「H」アイコンを右クリック ＞「Reload Script」で即座にリセットできます。
※色コードの個別指定は不要です。画面レイアウトや解像度が変わった場合のみ、\ キー（ひらがなの「ろ」／「ー」キー）で KeyAreaMinX と KeyAreaMaxX の2つの数字だけを調整してください。
