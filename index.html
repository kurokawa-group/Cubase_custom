Cubase 16 自動化スクリプト ガイド一覧

Windows環境で Cubase 16 の操作性を大幅に向上させる、AutoHotkey v2 用の自動化スクリプトと設定ガイドです。用途に合わせて統合版または単体版をお選びください。

1. スクリプト＆設定ガイド一覧

統合版：自動プリロール録音 ＋ 自動ホイールナッジ おすすめ・全部入り

2小節前からのプリロール自動録音と、MIDIノート選択直後だけのホイールナッジを1つのスクリプトで同時に実現します。
単体版：自動ホイールナッジのみ nudge.ahk

MIDIノートをクリックした直後だけマウスホイールが左右ナッジになり、他所クリックや領域外への移動で即座に通常スクロールへ戻ります。
単体版：自動プリロール録音のみ preroll.ahk

テンキー * で「プリロール＋クリック」を自動ONにして録音を開始し、停止（Space / 0）と同時に両方とも自動OFFに戻します。

2. AutoHotkey（オートホットキー）とは？

  • どんなソフト？：
    Windowsのキーボード操作・マウス操作・画面判定などを自動化・カスタマイズできる、無料のオープンソース常駐ユーティリティです。
  • Cubaseでのメリット：
    #HotIf という条件指定機能により、「Cubaseの画面がアクティブなときだけ動作する」ように制限できるため、ブラウザや他のソフトの操作を一切邪魔しません。
  • 軽量・安全：
    常駐時のメモリ消費はごくわずか（数MB程度）で、不要なときは画面右下のタスクトレイにある緑の「H」アイコンからいつでも一時停止・終了できます。

3. AutoHotkey v2 の入手とインストール手順

本ガイドのスクリプトはすべて最新の AutoHotkey v2.0（v2系） で動作します（古い v1.1 では動かないため必ず v2 をインストールしてください）。

  1. 公式サイトへアクセス：
    下のボタン（または検索で「AutoHotkey 公式」）から公式サイトを開きます。
    AutoHotkey 公式サイトを開く ↗
  2. インストーラーのダウンロード：
    トップページの 「Download」 ボタンをクリックし、「Download v2.0」（現在の最新安定版）を選択して AutoHotkey_2.0.xx_setup.exe を保存します。
  3. インストール実行：
    ダウンロードした .exe ファイルをダブルクリックし、画面の 「Install」 を押すだけで数秒で完了します（設定はすべて初期状態のままで問題ありません）。
  4. スクリプトの起動：
    インストール完了後は、各ガイドページからダウンロードした .ahk ファイルをダブルクリックするだけで自動的に常駐が始まります。
※インストール時に「v1とv2のどちらを使いますか？」と聞かれた場合は、v2 を選択してください。
