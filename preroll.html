Cubase 16 自動プリロール録音 設定ガイド（単体版）

Cubase 16 がアクティブなときだけ有効になり、2小節前からのプリロール＋クリック付き自動録音と、通常再生時の完全無音・隔離を実現します。

1. 操作割り当て一覧

操作方法Cubase上の動作内部処理（送信キー）
テンキー *2小節前プリロール＋クリック付き録音開始- ＋ c（ON）→ ^（録音）
Space / テンキー 0録音停止 ＋ プリロール＆クリック自動解除停止後 - ＋ c（OFF）
通常再生（Space）その場から100%無音で確認再生状態フラグ管理により誤作動ゼロ

2. Cubase 16 本体側の事前設定

  • メトロノーム設定（トランスポート ＞ メトロノーム設定 ＞ クリックオプション）：
    「録音中のクリック」と「再生中のクリック」の両方にチェックを入れます（プリロール区間は再生扱いとなるため両方必須です）。
  • トランスポートバーの初期状態：
    「プリロール（2.0.0.0）」と「メトロノーム（C）」の両方を OFF（消灯）にしておきます。
  • 環境設定 / スタートモード：
    「録音停止時にパンチインをオフ」と「停止時に開始位置に戻る」のチェックは外しておきます。
  • キーボードショートカット設定（編集 ＞ キーボードショートカット）：
    • トランスポート ＞ プリロールを使用：-（ハイフン）を割り当て
    • トランスポート ＞ 録音：標準のテンキー * を削除し、^（ハット）を割り当て
    • トランスポート ＞ 停止：テンキー 0（Num 0）が割り当てられていることを確認

3. AutoHotkey v2 スクリプト（プリロール単体版）

下のボタンから .ahk ファイルをダウンロードし、ダブルクリックして常駐させてください。

#Requires AutoHotkey v2.0

SetTitleMatchMode "RegEx"
#HotIf WinActive("ahk_exe i).*Cubase.*\.exe")

SetKeyDelay 10, 10
global IsPreRollOn := false

; 自動プリロール録音（テンキー * で録音 / スペース・0 で停止）
NumpadMult:: {
    global IsPreRollOn
    if (!IsPreRollOn) {
        SendEvent "{vkBD}" ; プリロール ON (-)
        Sleep 40
        SendEvent "c"      ; メトロノーム ON (c)
        IsPreRollOn := true
        Sleep 80
    }
    SendEvent "{vkDE}"     ; 録音開始 (^)
}

~Space::
~Numpad0::
~NumpadIns::
~0:: {
    global IsPreRollOn
    if (IsPreRollOn) {
        Sleep 80
        SendEvent "{vkBD}" ; プリロール OFF (-)
        Sleep 40
        SendEvent "c"      ; メトロノーム OFF (c)
        IsPreRollOn := false
    }
}

#HotIf

4. Windows起動時の自動常駐（スタートアップ登録）と運用

  • スタートアップ登録手順（UAC警告なし）：保存した .ahk ファイルを右クリック ＞「ショートカットの作成」を実行。Win + R を押して shell:startup と入力して開き、作成したショートカットをそのフォルダへ移動します（管理者昇格処理を省いているため、PC起動時に警告ダイアログなしで自動常駐します）。
  • 状態ズレのリセット：起動時は「プリロール」と「メトロノーム」が消灯していることを確認してください。手動操作等で状態が反転した場合は、タスクトレイの緑の「H」アイコンを右クリック ＞「Reload Script」で即座にリセットできます。
※「統合版（custom.ahk）」と併用するとキー操作が二重送信されて状態が反転するため、単体版を使用する場合は他の同系スクリプトを終了（Exit）した状態で常駐させてください（nudge.ahk との個別併用は可能です）。
