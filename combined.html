Cubase 16 自動プリロール録音＆自動ナッジ設定ガイド

Cubase 16 がアクティブなときだけ有効になり、2小節前からのプリロール自動録音（通常再生時は完全無音）と、MIDIノート選択中だけの自動ホイールナッジ（1msなど任意の単位で調整可能）を実現します。

1. 操作割り当て一覧

操作方法Cubase上の動作内部処理（送信キー）
テンキー *2小節前プリロール＋クリック付き録音開始- ＋ c（ON）→ ^（録音）
Space / テンキー 0録音停止 ＋ プリロール＆クリック自動解除停止後 - ＋ c（OFF）
ノート選択中に ホイール上右へナッジ（設定グリッド単位で後ろへ移動）]（片道スキャンON時）
ノート選択中に ホイール下左へナッジ（設定グリッド単位で前へ移動）[（片道スキャンON時）
空白クリック / Esc選択解除と同時に通常スクロールへ即復帰スキャンせず強制OFF

2. Cubase 16 本体側の事前設定

  • メトロノーム設定（トランスポート ＞ メトロノーム設定 ＞ クリックオプション）：
    「録音中のクリック」と「再生中のクリック」の両方にチェックを入れます。
  • トランスポートバーの初期状態：
    「プリロール（2.0.0.0）」と「メトロノーム（C）」の両方を OFF（消灯）にしておきます。
  • ナッジ単位（グリッド）の調整：
    エディタ上部のスナップ／グリッド設定で、1 ms や 1/16 など動かしたい任意の単位に調整可能です（スナップOFF時はズーム倍率に応じた微調整になります）。
  • キーボードショートカット設定（編集 ＞ キーボードショートカット）：
    • トランスポート ＞ プリロールを使用：-（ハイフン）を割り当て
    • トランスポート ＞ 録音：標準のテンキー * を削除し、^（ハット）を割り当て
    • トランスポート ＞ 停止：テンキー 0（Num 0）が割り当てられていることを確認
    • ナッジ ＞ 左へ移動 / 右へ移動：左へ [ 、右へ ] を割り当て

3. AutoHotkey v2 統合スクリプト（片道スキャン完全版）

下のボタンから .ahk ファイルをダウンロードし、ダブルクリックして常駐させてください。

#Requires AutoHotkey v2.0

if not A_IsAdmin {
    Run '*RunAs "' A_ScriptFullPath '"'
    ExitApp
}

SetTitleMatchMode "RegEx"
#HotIf WinActive("ahk_exe i).*Cubase.*\.exe")

SetKeyDelay 10, 10
global IsPreRollOn := false
global IsNoteSelectedFlag := false

; 【座標再取得用ヘルパー】レイアウト変更時に情報ライン白文字上で \ キーを押す
vkDC::
vkE2:: {
    CoordMode "Mouse", "Screen"
    CoordMode "Pixel", "Screen"
    MouseGetPos(&mx, &my)
    col := PixelGetColor(mx, my)
    A_Clipboard := "CheckX := " mx "`nTextColor := " col
    ToolTip "コピー完了 X:" mx " 色:" col
    SetTimer () => ToolTip(), -4000
}

; 1. 自動プリロール録音（テンキー * で録音 / スペース・0 で停止）
NumpadMult:: {
    global IsPreRollOn
    if (!IsPreRollOn) {
        SendEvent "{vkBD}"
        Sleep 40
        SendEvent "c"
        IsPreRollOn := true
        Sleep 80
    }
    SendEvent "{vkDE}"
}

~Space::
~Numpad0::
~NumpadIns::
~0:: {
    global IsPreRollOn
    if (IsPreRollOn) {
        Sleep 80
        SendEvent "{vkBD}"
        Sleep 40
        SendEvent "c"
        IsPreRollOn := false
    }
}

; 2. 解除時はスキャンしない「片道スキャン」方式の自動ナッジ
~LButton Up:: {
    global IsNoteSelectedFlag
    if (IsNoteSelectedFlag) {
        IsNoteSelectedFlag := false
        return
    }
    Sleep 60
    CoordMode "Pixel", "Screen"
    CheckX := 112
    TextColor := 0xB1B2B3
    if PixelSearch(&FoundX, &FoundY, CheckX, 150, CheckX, 950, TextColor, 15) {
        IsNoteSelectedFlag := true
    }
}

~Esc:: {
    global IsNoteSelectedFlag
    IsNoteSelectedFlag := false
}

#HotIf WinActive("ahk_exe i).*Cubase.*\.exe") && IsNoteSelectedFlag
WheelUp::SendEvent "{vkDD}"
WheelDown::SendEvent "{vkDB}"
#HotIf

4. Windows起動時の自動常駐（スタートアップ登録）と運用

  • スタートアップ登録手順：保存した .ahk ファイルを右クリック ＞「ショートカットの作成」を実行。Win + R を押して shell:startup と入力して開き、作成したショートカットをそのフォルダへ移動します。
  • 状態ズレのリセット：起動時は「プリロール」と「メトロノーム」が消灯していることを確認してください。手動操作等で状態が反転した場合は、タスクトレイの緑の「H」アイコンを右クリック ＞「Reload Script」で即座にリセットできます。
※画面レイアウトや解像度を変更した場合は、ノート選択中に情報ラインの白文字へマウスを乗せて \ キーを押すと、新しい CheckX と TextColor を取得できます。
